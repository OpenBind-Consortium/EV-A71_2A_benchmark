# Structural benchmark

This directory contains the processed structural benchmark data used for docking and co-folding evaluation on the OpenBind enteroviral 2A dataset.

## Contents

```text
structure/
└── processed_outputs/
    ├── annotated_complexes.csv
    ├── final_docking_pose_data.parquet
    ├── final_cofolding_pose_data.parquet
    └── fragment_followon_similarity.csv
```

### `annotated_complexes.csv`

Complex-level annotations for the crystallographic dataset, including fragment-screen labels, artefact annotations, PoseBusters validity, and benchmark filtering information.

This table defines the curated structural benchmark subsets used throughout the repository.

### `final_docking_pose_data.parquet`

Prepared pose-level docking results used for structural benchmark evaluation.

The underlying docking calculations and processing workflow are available from the [OpenBind docking repository](https://github.com/OpenBind-Consortium/openbind-docking).

### `final_cofolding_pose_data.parquet`

Prepared pose-level co-folding results in the common structural evaluation format.

The co-folding processing and evaluation workflow is available from [cofolding_evaluation](https://github.com/OmeirK/cofolding_evaluation).

### `fragment_followon_similarity.csv`

Fragment-to-follow-on assignments based on ECFP4 chemical similarity. The table records the most similar experimentally observed fragment for each follow-on compound and is used for the fragment-series analysis.

## Structural evaluation

Docking and co-folding results are evaluated using common pose-level metrics, including ligand heavy-atom RMSD, LDDT-PLI, and PoseBusters validity.

The final manuscript figures and summary tables are generated by:

```bash
python plotting/plot_figures.py
```
