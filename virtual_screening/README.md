# Virtual-screening benchmark

This directory contains the OpenBind enteroviral 2A protease virtual-screening benchmark and the processed compound-level scores used for evaluation.

The benchmark combines experimentally observed binders with suspected non-binders derived from technically successful crystallographic soaking experiments in which no binding event was detected. Here, suspected non-binders are defined from the crystallographic soaking outcome rather than from a biochemical determination of binding status.

The benchmark is restricted to follow-on compounds. Compounds from the fragment-screen libraries are excluded, together with small fragment-like compounds from the designed compound collections.

The final benchmark contains 2,084 compounds, comprising 566 binders and 1,518 suspected non-binders.

## Contents

```text
virtual_screening/
├── benchmark/
│   ├── virtual_screening_benchmark.csv
│   └── virtual_screening_benchmark_summary.csv
├── results/
├── scripts/
└── soakdb_lb32627-66.csv
```

`benchmark/virtual_screening_benchmark.csv` is the final compound-level benchmark used by the analysis workflow and contains:

```text
Name,SMILES,is_binder
```

`results/` contains the processed compound-level ranking scores used for virtual-screening evaluation. Score files follow the common format:

```text
Name,is_binder,score
```

with scores oriented such that larger values correspond to higher predicted binder ranking.

## Rebuilding the benchmark

The benchmark can be regenerated from the SoakDB export and curated crystallographic annotations with:

```bash
python virtual_screening/scripts/build_virtual_screening_benchmark.py \
    --soakdb virtual_screening/soakdb_lb32627-66.csv \
    --annotated-complexes structure/processed_outputs/annotated_complexes.csv \
    --output virtual_screening/benchmark/virtual_screening_benchmark.csv \
    --summary virtual_screening/benchmark/virtual_screening_benchmark_summary.csv
```

The construction workflow applies the experimental quality criteria used to define suspected non-binders, excludes compounds with crystallographic binding evidence, resolves compound identities, removes covalent-library compounds, excludes fragment-screen and small fragment-like compounds, and validates that compounds can be represented as 3D molecular structures.

## Benchmark characterisation

Chemical-space and physicochemical characterisation of the benchmark is generated by:

```text
plotting/scripts/plot_virtual_screening_characterisation.py
```

The analysis includes ECFP4-based nearest-neighbour similarities, representative binder/non-binder pairs, UMAP projection of the benchmark chemical space, and physicochemical descriptor distributions.

These figures and associated summary tables are regenerated as part of the main plotting workflow:

```bash
python plotting/plot_figures.py
```

## Performance evaluation

Processed virtual-screening scores are evaluated by:

```text
plotting/scripts/plot_virtual_screening_performance.py
```

The analysis reports ROC-AUC, average precision, and enrichment factors at 1%, 2%, and 5%.

The manuscript comparison uses the common benchmark set of 2,084 compounds across the evaluated methods.
